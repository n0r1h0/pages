Antigravity CLI で Adobe Analytics MCP に接続する

Google の Antigravity CLI から、Adobe 公式のリモート MCP サーバー Adobe Analytics MCP に接続する実践ガイドです。核心は、24時間で失効する IMS トークンを、ローカルの stdio プロキシでオンデマンド自動更新すること。実際に動いた構成をそのまま載せます。

Gemini CLI を使う人は、このガイドは不要

Gemini CLI なら、この手順（stdio プロキシ）は要りません。 Claude・ChatGPT と同じように、MCP サーバーとして URL https://aa-mcp.adobe.io/mcp を登録し、ブラウザで Adobe ID ログインするだけで繋がります（対話OAuth）。認証情報の発行もプロキシも不要です。
本ガイドは、その対話OAuthが使えない Antigravity CLI 向けの回避策（Server-to-Server ＋ ローカルプロキシ）をまとめたものです。

ただし既知の不具合（findReportSuites）に注意: どのクライアントでも、findReportSuites 等で Invalid input: expected record, received array が出ることがあります。サーバーが structuredContent を最上位「配列」で返しており（MCP 仕様上は「オブジェクト」であるべき違反）、Zod 等で厳密検証する MCP クライアント（Claude Desktop 系など）は invalid_type として弾きます。一方 claude.ai コネクタ経由など検証が緩いクライアントではエラーにならず配列がそのまま返ります。クライアント側では直せないため、当面はエラーが出ないクライアント経由で使うか、生の HTTP レスポンスを見て後続処理側で配列を想定して扱う（Adobe 側の仕様修正待ち）。

TL;DR
  • 接続先は Adobe 公式のリモート MCP https://aa-mcp.adobe.io/mcp（Adobe Analytics MCP）。
  • 認証トークン（Adobe IMS）は約24時間で失効するため、設定に直書きすると翌日 401 で止まる。
  • 対策はローカル stdio プロキシ（adobe_mcp_proxy.py、Python 標準ライブラリのみ）。ツール呼び出し時にトークンをオンデマンド自動更新し、401 なら再取得して1回リトライ。常駐・cron 不要。
  • Antigravity CLI の mcpServers に command: python3 ＋ プロキシの絶対パスを書くだけ（stdio）。この構成は Antigravity CLI（agy）で検証済み。
  • そもそも Antigravity で対話OAuthが使えないのは、Adobe が Antigravity のリダイレクトURIを拒否するため（→ §03）。プロキシはその回避策。
  • 事前準備: Adobe Developer Console で OAuth Server-to-Server 資格情報を発行し、MCP/Analytics 権限を付与。

01全体像と「24時間で失効する」課題

この手順について

本ガイドは Antigravity CLI（agy）で実際に構築・検証したサンプルです。Antigravity CLI はリダイレクトURIの制限で対話OAuthが使えないため、Server-to-Server 認証＋ローカルの stdio プロキシで接続します（理由は §03）。

登場人物は3つです。①MCP クライアント（Antigravity CLI）、②MCP サーバー（Adobe がホストする https://aa-mcp.adobe.io/mcp）、③認証（Adobe IMS が発行する OAuth トークン）。

問題は③です。Adobe Analytics MCP への通信には Adobe IMS の OAuth Access Token が必要ですが、この有効期限は約24時間（86,400秒）。トークンを設定ファイルに直書きすると、翌日には HTTP 401 でツールが動かなくなります。

この構成の解決策

ローカルに stdio MCP プロキシ（adobe_mcp_proxy.py）を置きます。クライアントが MCP ツールを呼んだ瞬間にプロキシが起動し、トークンの残り時間を判定。切れていれば POST /ims/token/v3 で取得し直してキャッシュし、リモートの MCP サーバーへ中継します。常駐デーモンや cron は不要で、利用時のみ動きます。401 を受けたら強制再取得して1回だけ自動リトライします。

プロキシは Python 3 標準ライブラリのみ（urllib 等）で実装でき、pip install は不要です。

02Adobe 側の準備（認証情報を発行する）

Adobe Developer Console で API 資格情報を発行し、Analytics の権限を紐付けます。

  1. プロジェクトを作成する

    Developer Console にログインし、画面右上の組織（IMS Org）が対象組織であることを確認して Create new project。

  2. Adobe Analytics API を追加する

    Add to Project → API → Adobe Analytics を選択して Next。

  3. OAuth Server-to-Server を選ぶ

    認証方式で OAuth Server-to-Server を選択（旧 Service Account JWT は非推奨）。Credential 名を付けて保存。

  4. Product Profile（権限）を紐付ける

    対象レポートスイートの閲覧権限を含む Adobe Analytics 製品プロファイルを選び Save configured API。権限が不足すると unauthorized_metric / unauthorized_dimension エラーになります。

  5. 認証情報を控える

    Client ID / Client Secret / Organization ID（...@AdobeOrg）/ Scopes をコピーします。加えて Adobe Analytics の Global Company ID（例 adoben1b）も控えます。

MCP サーバーへ送るリクエストには、これらが以下の HTTP ヘッダーとして必要です（プロキシが自動付与します）。

ヘッダー値
AuthorizationBearer <IMS Access Token>
x-api-keyClient ID
x-gw-ims-org-idOrganization ID（@AdobeOrg）
x-global-company-idGlobal Company ID
Content-Typeapplication/json
Acceptapplication/json, text/event-stream

03なぜプロキシが必要か（Antigravity の制限）

サーバー（aa-mcp.adobe.io）は対話OAuthを完全にサポートしています（WWW-Authenticate と .well-known を広告し、動的クライアント登録＝DCR・authorization_code・PKCE 対応）。つまり本来なら「URL を登録してブラウザログイン」で繋がるはずです。分かれ目はクライアントのリダイレクトURIを Adobe が受理するかでした。実測では:

クライアントの redirect URIAdobe DCR の応答結果
ループバック http://localhost:<port>/oauth/callback 201 Created（受理） 対話OAuthが成立
Antigravity の固定 URI https://antigravity.google/oauth-callback 400 invalid_redirect_uri（拒否） ブラウザ認証が起動せず unauthorized のまま

これは Antigravity CLI 側の制限

Antigravity は固定のリダイレクトURI https://antigravity.google/oauth-callback を使いますが、これを Adobe の DCR が拒否します。Antigravity はこの URI を変更できないため、対話OAuthは事実上使えません。そこで本ガイドでは、Server-to-Server（S2S）認証＋ローカル stdio プロキシで接続します。S2S には refresh token が無く 24時間で失効するため、プロキシがトークンをオンデマンドで再取得して補います（→ §04）。

4.1 認証設定 adobe_auth_config.json

各値を自分の環境のものに置き換えます。scopes は Developer Console の資格情報に表示される文字列を使います。

{
  "client_id": "YOUR_CLIENT_ID",
  "client_secret": "YOUR_CLIENT_SECRET",
  "org_id": "YOUR_ORG_ID@AdobeOrg",
  "global_company_id": "YOUR_GLOBAL_COMPANY_ID",
  "scopes": "additional_info.job_function,openid,AdobeID,target_sdk,additional_info.roles,read_organizations,additional_info.projectedProductContext",
  "serverUrl": "https://aa-mcp.adobe.io/mcp"
}

注意 — シークレットの保護

作成後、所有者のみアクセス可に制限します: chmod 600 adobe_auth_config.json。この値は .gitignore で Git 管理外にします。

4.2 プロキシ本体 adobe_mcp_proxy.py

保存して実行権限を付与します: chmod +x adobe_mcp_proxy.py。外部依存はなく Python 3.8+ で動きます。

adobe_mcp_proxy.py（全文・クリックで展開） 
#!/usr/bin/env python3
"""
Adobe Analytics MCP Stdio Proxy
-------------------------------
Acts as a local stdio MCP server that proxies all JSON-RPC requests
to the remote Adobe Analytics MCP server (https://aa-mcp.adobe.io/mcp).

Token Management:
- Completely on-demand (no cron, no background daemons).
- When the AI client uses MCP, this proxy automatically checks token validity.
- If expired or missing, it transparently requests a new token from Adobe IMS
  and caches it for future calls.
- If a 401 Unauthorized occurs, it automatically refreshes the token and retries.
"""

import base64
import json
import os
import pathlib
import sys
import time
import urllib.error
import urllib.parse
import urllib.request

IMS_TOKEN_URL = "https://ims-na1.adobelogin.com/ims/token/v3"
DEFAULT_MCP_REMOTE_URL = "https://aa-mcp.adobe.io/mcp"
SCRIPT_DIR = os.path.dirname(os.path.abspath(__file__))
DEFAULT_CONFIG_PATH = os.path.join(SCRIPT_DIR, "adobe_auth_config.json")
TOKEN_CACHE_FILE = os.path.join(SCRIPT_DIR, ".token_cache.json")


def debug_log(msg: str):
    """Log to stderr so as not to interfere with MCP JSON-RPC on stdout."""
    sys.stderr.write(f"[adobe-mcp-proxy] {msg}\n")
    sys.stderr.flush()


class AdobeMcpProxy:
    def __init__(self, config_path: str = DEFAULT_CONFIG_PATH):
        self.config_path = config_path
        self.config = self.load_config()
        self.remote_url = self.config.get("serverUrl", DEFAULT_MCP_REMOTE_URL)
        self.access_token = None
        self.expires_at = 0
        self.session_id = None
        self.load_cached_token()

    def load_config(self) -> dict:
        cfg = {}
        if os.path.isfile(self.config_path):
            try:
                with open(self.config_path, "r", encoding="utf-8") as f:
                    cfg = json.load(f)
            except Exception as e:
                debug_log(f"Warning: Failed to load config from {self.config_path}: {e}")

        return {
            "client_id": cfg.get("client_id") or os.environ.get("ADOBE_CLIENT_ID", ""),
            "client_secret": cfg.get("client_secret") or os.environ.get("ADOBE_CLIENT_SECRET", ""),
            "org_id": cfg.get("org_id") or os.environ.get("ADOBE_ORG_ID", ""),
            "global_company_id": cfg.get("global_company_id") or os.environ.get("ADOBE_GLOBAL_COMPANY_ID", ""),
            "scopes": cfg.get("scopes") or os.environ.get(
                "ADOBE_SCOPES",
                "additional_info.job_function,openid,AdobeID,target_sdk,additional_info.roles,read_organizations,additional_info.projectedProductContext"
            ),
            "serverUrl": cfg.get("serverUrl", DEFAULT_MCP_REMOTE_URL),
        }

    def load_cached_token(self):
        """Load token from disk cache if still valid."""
        if not os.path.isfile(TOKEN_CACHE_FILE):
            return
        try:
            with open(TOKEN_CACHE_FILE, "r", encoding="utf-8") as f:
                data = json.load(f)
            token = data.get("access_token")
            exp = float(data.get("expires_at", 0))
            if token and exp > time.time() + 60:
                self.access_token = token
                self.expires_at = exp
                debug_log(f"Loaded cached token (valid for {(exp - time.time()) / 3600:.1f} more hours)")
        except Exception as e:
            debug_log(f"Failed to read token cache: {e}")

    def save_cached_token(self, token: str, expires_in: float):
        """Save token to disk cache."""
        self.access_token = token
        self.expires_at = time.time() + expires_in
        try:
            with open(TOKEN_CACHE_FILE, "w", encoding="utf-8") as f:
                json.dump({"access_token": token, "expires_at": self.expires_at}, f)
            os.chmod(TOKEN_CACHE_FILE, 0o600)
        except Exception as e:
            debug_log(f"Failed to save token cache: {e}")

    def get_valid_token(self, force_refresh: bool = False) -> str:
        """Return a valid token, refreshing on-demand if necessary."""
        now = time.time()
        # Refresh if token missing, expired, or less than 5 minutes remaining
        if not force_refresh and self.access_token and (self.expires_at - now > 300):
            return self.access_token

        debug_log("Refreshing Adobe IMS Access Token on-demand...")
        client_secret = self.config.get("client_secret")
        if not client_secret:
            raise ValueError("Client secret is missing in adobe_auth_config.json")

        form_data = urllib.parse.urlencode({
            "client_id": self.config["client_id"],
            "client_secret": client_secret,
            "grant_type": "client_credentials",
            "scope": self.config["scopes"],
        }).encode("utf-8")

        req = urllib.request.Request(
            IMS_TOKEN_URL,
            data=form_data,
            headers={
                "Content-Type": "application/x-www-form-urlencoded",
                "User-Agent": "Adobe-MCP-Proxy/1.0",
            },
            method="POST",
        )

        try:
            with urllib.request.urlopen(req, timeout=30) as resp:
                resp_data = json.loads(resp.read().decode("utf-8"))
            new_token = resp_data.get("access_token")
            expires_in = float(resp_data.get("expires_in", 86400))
            if not new_token:
                raise RuntimeError(f"Unexpected token response: {resp_data}")

            self.save_cached_token(new_token, expires_in)
            debug_log(f"New access token obtained successfully (expires in {expires_in / 3600:.1f}h)!")
            return new_token
        except urllib.error.HTTPError as e:
            err = e.read().decode("utf-8")
            raise RuntimeError(f"Adobe IMS error (HTTP {e.code}): {err}") from e

    def forward_request(self, payload: dict, retry_count: int = 0) -> dict | None:
        """Forward JSON-RPC request to the remote Adobe MCP endpoint."""
        token = self.get_valid_token()
        headers = {
            "Authorization": f"Bearer {token}",
            "x-api-key": self.config["client_id"],
            "x-gw-ims-org-id": self.config["org_id"],
            "x-global-company-id": self.config["global_company_id"],
            "Content-Type": "application/json",
            "Accept": "application/json, text/event-stream",
        }
        if self.session_id:
            headers["Mcp-Session-Id"] = self.session_id

        data = json.dumps(payload).encode("utf-8")
        req = urllib.request.Request(self.remote_url, data=data, headers=headers, method="POST")

        try:
            with urllib.request.urlopen(req, timeout=60) as resp:
                sess = resp.headers.get("Mcp-Session-Id") or resp.headers.get("X-Session-Id")
                if sess:
                    self.session_id = sess
                resp_body = resp.read().decode("utf-8")
                if not resp_body.strip():
                    return None
                return json.loads(resp_body)
        except urllib.error.HTTPError as e:
            if e.code == 401 and retry_count == 0:
                debug_log("Received 401 Unauthorized from Adobe MCP server. Retrying with fresh token...")
                self.get_valid_token(force_refresh=True)
                return self.forward_request(payload, retry_count=1)
            err_body = e.read().decode("utf-8")
            debug_log(f"HTTP Error {e.code} from remote server: {err_body}")
            req_id = payload.get("id")
            if req_id is not None:
                return {
                    "jsonrpc": "2.0",
                    "id": req_id,
                    "error": {
                        "code": -32603,
                        "message": f"Remote MCP error ({e.code}): {err_body}",
                    },
                }
            return None
        except Exception as e:
            debug_log(f"Communication error with remote MCP: {e}")
            req_id = payload.get("id")
            if req_id is not None:
                return {
                    "jsonrpc": "2.0",
                    "id": req_id,
                    "error": {
                        "code": -32603,
                        "message": f"Proxy communication error: {str(e)}",
                    },
                }
            return None

    def run(self):
        """Main stdio loop reading JSON-RPC lines from stdin and writing to stdout."""
        debug_log("Adobe MCP Stdio Proxy started.")
        while True:
            try:
                line = sys.stdin.readline()
                if not line:
                    break
                line = line.strip()
                if not line:
                    continue

                try:
                    payload = json.loads(line)
                except json.JSONDecodeError as e:
                    debug_log(f"Invalid JSON received on stdin: {e}")
                    continue

                method = payload.get("method", "response")
                req_id = payload.get("id")
                debug_log(f"Processing method='{method}', id={req_id}")

                res = self.forward_request(payload)
                if res is not None:
                    out_line = json.dumps(res, ensure_ascii=False)
                    sys.stdout.write(out_line + "\n")
                    sys.stdout.flush()

            except (KeyboardInterrupt, SystemExit):
                break
            except Exception as e:
                debug_log(f"Unexpected error in proxy loop: {e}")

        debug_log("Adobe MCP Stdio Proxy stopped.")


if __name__ == "__main__":
    proxy = AdobeMcpProxy()
    proxy.run()

05Antigravity CLI に登録する

プロキシは stdio サーバーなので、Antigravity のグローバル設定 ~/.gemini/config/mcp_config.json（またはワークスペースの .agents/mcp_config.json）の mcpServers に、command ＋ args でプロキシの絶対パスを指定するだけです。

{
  "mcpServers": {
    "adobe-analytics": {
      "command": "python3",
      "args": ["/ABSOLUTE/PATH/TO/adobe-mcp-proxy/adobe_mcp_proxy.py"]
    }
  }
}

/ABSOLUTE/PATH/TO/ は実際の絶対パスに置き換えてください。追記後、CLI のプロンプトで /mcp を実行するとマネージャーが開き、adobe-analytics のステータスが active になれば接続完了です。

AI エージェントから呼ぶ

Antigravity CLI で自然文で頼めば、ツールが透過的に実行されます。

  • 「Adobe Analytics の現在のサーバー日時を取得して」（getServerDateTime）
  • 「利用可能なレポートスイートの一覧を出して」（findReportSuites）
  • 「ページ別 PV のレポートを出して」（runReport）

推奨の初期化フロー（Bootstrap）

  1. describeAa を guideType: "REPORT_SUITE_CONTEXT_GUIDE" で実行し、利用ガイドをロード。
  2. findCompanies で globalCompanyId、findReportSuites で対象 rsid を特定。
  3. setSessionDefaults に reportSuiteId と globalCompanyId を渡す（以降は引数省略可）。
  4. 相対期間を扱う前に getServerDateTime でサーバー基準日を取得し、ISO 8601 で runReport を実行。
