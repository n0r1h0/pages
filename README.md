# pages

個人で書き溜めている学習メモ・技術ノートを公開するためのナレッジサイトです。特定の製品やトピックに限定せず、Adobe 製品の解説から LLM エンジニアリングまで、扱う範囲を広げながら育てていきます。

公開ページ: https://n0r1h0.github.io/pages/

## 収録カテゴリ

| カテゴリ | 内容 |
|----------|------|
| [`adobe-analytics/`](adobe-analytics/) | Adobe Analytics のセグメント機構に関する学習資料（[n0r1h0/Segment](https://github.com/n0r1h0/Segment) より移植） |
| [`llm-engineering/`](llm-engineering/) | LLM サービス・エージェントの内部構造（Skill 実行、RAG、実行ループなど） |

## 構成方針

- 各カテゴリはフォルダ単位で独立し、フォルダ直下の `README.md` が索引を兼ねます。
- 各記事は自己完結した静的 HTML（スタイル・スクリプト込み）として配置し、GitHub Pages でそのまま配信します。
- ルートの [`index.html`](index.html) がサイト全体のトップページで、各カテゴリ・記事へのリンク集になっています。
